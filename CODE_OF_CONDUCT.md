# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good faith, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, insults, personal or political attacks, and publishing others' private information are not tolerated.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the maintainer through GitHub (open a private security advisory on this repository and mention it's a conduct report). All reports are reviewed promptly and handled confidentially.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that don't follow this Code of Conduct, and may ban contributors temporarily or permanently for repeated or serious violations.
