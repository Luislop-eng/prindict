Privacy

Ultimo aggiornamento: 15 ottobre 2026

In breve: Prindict non ha server né account, non usa cookie, statistiche o tracciamento. Le tue clip restano sul tuo computer. Il riconoscimento vocale però è fornito dal browser: in Chrome l'audio viene trascritto dai server di Google.

Chi siamo

Prindict è un progetto open source gratuito, senza scopo commerciale, pubblicato da Luigi Loperfido. Per domande sulla privacy apri una segnalazione privata dal repository GitHub.

Cosa resta sul tuo dispositivo

  • Impostazioni (tema, font, colori, grandezza testo) e l'eventuale immagine di sfondo sono salvate nel localStorage del tuo browser, solo per ricordare le tue scelte. Puoi cancellarle svuotando i dati del sito.
  • Le registrazioni vengono create nel browser e restano lì finché non le scarichi. Non vengono caricate da nessuna parte.
  • Font inclusi nell'app: nessuna richiesta a Google Fonts o ad altri servizi esterni.

Riconoscimento vocale

Per trasformare la voce in testo Prindict usa la Web Speech API del browser. In Chrome (ed Edge) questa funzione invia l'audio del microfono ai server del produttore del browser (Google per Chrome) per la trascrizione, secondo la privacy di Google. Prindict non riceve né conserva questo audio. Il microfono si attiva solo quando premi Anteprima o Registra, e il browser ti chiede il permesso. Evita di dettare informazioni sensibili.

Hosting

Il sito è ospitato da GitHub Pages (GitHub, Inc.). Come ogni server web, GitHub può registrare dati tecnici delle visite (es. indirizzo IP) per sicurezza e funzionamento: vedi la privacy di GitHub.

English summary

Prindict has no server, accounts, cookies, analytics or tracking. Settings and your background image are stored in your browser's localStorage; recordings never leave your device unless you download them; fonts are self-hosted. Speech recognition is done by your browser: in Chrome, microphone audio is sent to Google for transcription. The site is hosted on GitHub Pages, which may log technical data such as IP addresses.
